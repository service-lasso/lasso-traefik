# lasso-traefik

`lasso-traefik` is the canonical Service Lasso service repo for packaging Traefik as a release-backed baseline service.

The repo does not fork Traefik. It downloads the official Traefik binary release, wraps it in Service Lasso-compatible platform archives, and publishes those archives from protected `main` pushes using the project version pattern:

```text
yyyy.m.d-<shortsha>
```

## Release Assets

Each release publishes:

- `lasso-traefik-win32.zip`
- `lasso-traefik-linux.tar.gz`
- `lasso-traefik-darwin.tar.gz`
- `service.json`

The archives contain the Traefik binary plus a small package metadata file. Runtime config is generated by Service Lasso from `service.json` during the `config` action.

## Local Verification

```powershell
npm test
```

This packages the current platform, extracts the archive, runs `traefik --version`, starts Traefik with a temporary ping-enabled config, checks `/ping`, and shuts the process down.

## Service Lasso Contract

The service manifest declares:

- native archive acquisition from GitHub releases
- generated Traefik static config under `runtime/traefik.yml`
- a lightweight dynamic config placeholder under `runtime/dynamic.yml`
- dashboard/ping and web entrypoint ports
- process health for Service Lasso lifecycle readiness
